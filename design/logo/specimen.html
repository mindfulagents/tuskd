OpenTusk

Local, single-binary memory for AI agent swarms — and a visual identity to match: a natural-history field journal, not a SaaS gradient. The mammoth is the memory; the amber is what preserves it; the tar is the ground it's dug out of.

Concept — deep memory

The woolly mammoth: memory that outlasts the ice age, sturdy, off-grid, excavated intact millennia later — which is exactly the pitch for a local Markdown vault. The mark is kept as an engraved line drawing (a specimen plate, not a mascot) so it sits naturally beside serif headings and monospace labels. Amber is the accent everywhere: tusk ivory in warm light, and fossil resin — the stuff that preserves things perfectly.

The mark — three weights, three jobs

One drawing, three tiers. Fine for display, bold for UI chrome, and below 32 px the mammoth hands off to the tusk glyph — never scale the full drawing into a favicon.

fine · ≥96px · display, docs, posters
bold · 32–96px · UI, header, README
on bone · use deep tusk or ink
glyph · ≤32px · favicon, terminal, pin

Badge

For avatars (GitHub org, social, MCP client icons). Bone mammoth on soot, single amber ring. Holds up at 80 px; below that, use the glyph.

Lockups

Serif wordmark (Charter), "Open" in ground color, "Tusk" in amber. Clearspace: half the mammoth's height on all sides. Don't set the wordmark in the mono face — mono is for labels and code only.

Rules

  • One color per mark. The mammoth is always monochrome — amber, bone, or ink. Never multicolor, never gradient-filled.
  • Respect the tiers. Fine ≥ 96px, bold 32–96px, glyph ≤ 32px. The drawing is the hero at large sizes; the tusk carries the identity at small ones.
  • Warm grounds only. Tar/Soot or Bone. If the mark must sit on a photo or foreign color, use the badge.
  • The mammoth faces right. Don't mirror it — the trunk-and-tusk silhouette is the recognizable edge.
  • Wordmark is serif. "Open" in ground color, "Tusk" in amber. Mono is reserved for labels (MEMORY FOR AGENT SWARMS) — never the name.
